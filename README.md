# OmniFinder (万象探索) - 个人网络资源与多媒体探索工具 (学习研究版)

本工具为个人网络技术研究与多媒体检索学习工具，支持多语言、多协议与深度检索。

## 目录结构
- `main_ui.py`: PyQt5 桌面主程序界面（网址输入、类型勾选树、资源列表表格、进度条、实时日志、内置硬件加速播放器）
- `sniffer_magic.py`: 二进制文件指纹识别
- `sniffer_engine.py`: 网络与 DOM 嗅探引擎
- `resource_searcher.py`: 全网多维资源检索引擎（含剧情逆向溯源、网盘暗搜、全球 DHT 磁力检索）
- `downloader.py`: 下载与多媒体处理引擎
- `build_exe.py`: 一键打包为 Windows `.exe` 的打包脚本

## 本地启动与测试
```bash
python3 main_ui.py
```
